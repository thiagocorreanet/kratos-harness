# Comment editing requirements

## Purpose

Let the author of a comment correct it.

## Rules

1. Only the member who wrote a comment may edit it.
2. A comment may be edited for 15 minutes after it was posted, measured from
   the stored creation time.
3. An edited comment shows the label "edited" and the time of the last edit.
4. Every edit is stored, and an administrator may read the full edit history.
5. Editing a comment does not send a new notification.
6. A deleted comment cannot be edited.

## Dependencies

None beyond the existing comment store.

## Out of scope

Comment deletion and moderation.
