# Final review fix report

## Scope and outcome

Resolved all three Important and both Minor final-review findings without
changing gate evaluation or aggregation decisions. The new
`host.phase-handoff@1.4.0` and `host.doctor-report@1.0.0` diagnostic arrays now
carry the evaluator maximum of 265 findings. Doctor detail lines allow the same
cardinality and preserve valid duplicate summaries.

Published predecessor schema JSON files are unchanged. The only schema-tree
changes relative to baseline `12d7032` are the two branch-new host schemas and
`schemas/README.md`:

```text
schemas/README.md
schemas/host/doctor-report.v1.schema.json
schemas/host/phase-handoff.v1.4.schema.json
```

No dependency was added. `npm run verify` was deliberately not run; the
coordinator owns that final HEAD-wide verification.

## Root cause and implementation

- Both new diagnostic contracts reused
  `state.event.v1.3#/$defs/gateFailures`, whose event-specific maximum is eight.
  Each host schema now owns a `maxItems: 265` array while reusing only the
  published `gateFailure` item definition.
- Doctor `details` had `maxItems: 64` and `uniqueItems: true`; it now permits
  265 safe lines without deduplication.
- Large schema-valid structured payloads were still rejected because their
  canonical one-line JSON was passed to the 4,096-character human-line
  validator. Handoff and doctor now validate every public string recursively,
  retaining secret/path sanitization without applying a human-line bound to the
  whole JSON document.
- Regenerated declarations changed both diagnostic traces from the event's
  eight-element tuple union to bounded arrays. That allowed removal of the
  handoff trace cast; the phase-dependent handoff union cast remains unrelated
  to cardinality.
- Canonical fixtures now represent runtime semantics: shadow outcome `pass`,
  `gaps-closed` priority 50, blockers as gate IDs, and evaluator-shaped evidence
  and detail fields. Semantic tests enforce these facts.
- Contract guides now name current selectors from `CONTRACT_VERSIONS`, and the
  acceptance evidence maps the lifecycle and predecessor criteria to their
  exact tests.
